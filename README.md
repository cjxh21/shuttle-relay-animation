# 迎面接力 · 绕杆接棒教学动画

纯前端 HTML5 Canvas 交互式体育教学动画，演示室外体育场 **100 m 直道中间 60 m（20 m–80 m）** 的迎面接力比赛与核心**绕杆交接棒**技术动作。

## 核心演示要点

1. **比赛场地与编队**：室外 400 m 标准体育场的 100 m 直道，取中间 **60 m**（20 m 与 80 m 处各设一根标志杆），两端杆后各站 **10 位同学**排成纵队。
2. **持棒跑向左侧**：持棒同学向对面跑进时偏向**自己的左侧**，让标志杆处于右手一侧，跑过杆线至杆后再交棒。
3. **接棒站位与伸手**：接棒同学站在杆后，**身体在自己的左侧**，**接棒手（惯用手、右手，红色护腕标识）伸向右侧**，停在标志杆正后方等候。
4. **绕杆接棒（重点）**：右手接右手后，接力棒**从杆后经过、由右向左**拉回身体左侧跑动位置（棒绕标志杆呈 **“U” 形轨迹**），随后**立即起跑**。

## 交互功能

- **▶ 完整接力演示**：鸟瞰进入 60 m 赛区，完整演示 20 棒迎面接力，支持交接棒自动特写与慢动作。
- **🔍 绕杆接棒分解**：聚焦标志杆区域，支持连贯慢放或一键定格查看 4 个分解步骤。
- **⚖ 正误对比**：直观对比“未绕杆在杆前交接（犯规）”与“绕杆在杆后由右向左交接（正确）”。
